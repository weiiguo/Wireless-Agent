# WirelessAgent: Large Language Model Agents for Intelligent Wireless Networks
This is an official implementation of the paper [WirelessAgent: Large Language Model Agents for Intelligent Wireless Networks](https://arxiv.org/abs/2409.07964).

**Update at May 2025:**

The above magazine paper has been extended to a journal version and submitted for possible publication. Please refer to the updated verision at [arXiv](https://arxiv.org/abs/2505.01074). 

This repo will no longer be updated and please find the updates at a [new repository](https://github.com/jwentong/WirelessAgent_R1).
